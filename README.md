# Azur Byron Bay — Luxury Boutique Accommodation Website

> A bespoke, luxury boutique accommodation website for **Azur Byron Bay** (44 Shirley Street, Byron Bay, NSW), faithfully crafted in the layout and design aesthetic of **[Aloha Byron Bay](https://www.alohabyronbay.com.au/)** with a mobile app-grade responsive experience.

---

## 🌴 Property Overview

- **Location**: 44 Shirley Street, Byron Bay, NSW 2481, Australia (5 minutes walk to Byron town centre and Main Beach)
- **Estate Capacity**: Up to 22 guests across the estate
- **Dwellings**:
  - **4BR Beach House + The Pass**: Signature coastal retreat with private heated pool & spa, wrap-around deck, luxury kitchen.
  - **3BR Meraki Condo**: Contemporary Balinese luxury, sun deck, plunge pool access.
  - **1BR Poolside Suites**: Sea Breeze, Tallows, The Wreck, and Wategos — intimate boutique king retreats opening onto the central pool, heated spa, and tropical gardens.
  - **Exclusive Estate Hire**: Group bookings and private retreats for up to 22 guests.

---

## ✨ Design & Features

- **Aloha Byron Bay Layout Alignment**:
  - **Crisp White Navbar**: Left-aligned brand logo, clean uppercase letter-spaced navigation, and signature earth-tone (`#8e7060`) `BOOK NOW` button.
  - **Panoramic 3-Panel Hero Showcase**: Continuous photo slider highlighting property grounds, living spaces, and poolside suites, with arrow navigation and a **"▶ Watch Video Tour"** modal trigger.
  - **Centered Editorial Story Section**: *"Experience Boutique Byron Bay Living."* with tracked kicker and warm earth-tone CTA.
  - **"ACCOMMODATION OPTIONS" 4-Card Grid**: Beach House, Meraki Condo, Poolside Suites, and Group Bookings with centered earth-tone badges and subtle hover animations.
  - **Signature Aloha Earth-Tone Footer**: Warm mocha brown background (`#886b5c`), centered `NAME` and `EMAIL` newsletter inputs, bold `SUBSCRIBE` button, and horizontal footer links.
- **Mobile App-Grade UX**:
  - **Fixed Bottom App Dock**: `Home`, `Rooms`, elevated `BOOK` pill, `Layout`, and `Gallery` with native safe-area inset support.
  - **Slide-Up Bottom Sheet Modal**: Gesture-friendly booking drawer with drag handle, guest stepper (`−` / `+`), and date selectors.
  - **Touch-Friendly Panoramas**: 92% width cards with momentum snap-scrolling.
- **Interactive Estate Floor Plan**: Architectural layout tabs (*Estate Masterplan*, *Beach House & The Pass*, *Meraki Condo*, *Poolside Suites*) with zoomable lightbox.
- **Media Tours**: Integrated video player modals for full property and dwelling walkthroughs.

## 🛠️ Technology Stack

- **Frontend**: HTML5, Vanilla CSS3 (Custom Design System with Cormorant Garamond & Plus Jakarta Sans), Vanilla JavaScript (ES Modules).
- **Tooling & Bundler**: Vite (Multi-page configuration).
- **Version Control**: Git & Git LFS for video assets.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [Git](https://git-scm.com/) and [Git LFS](https://git-lfs.github.com/)

### Installation & Local Run

```bash
# 1. Clone repository
git clone https://github.com/jiya1218/Azur-Bayron-Bay.git
cd Azur-Bayron-Bay

# 2. Pull Git LFS media files (if applicable)
git lfs pull

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Visit `http://localhost:3000/` in your browser.

### Production Build

```bash
npm run build
```
